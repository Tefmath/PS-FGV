Boas práticas:

-> python -m venv .venv
vai criar um ambiente virtual com esse nome, pra baixar as bibliotecas

-> .\.venv\Scripts\activate
se der ruim nas politicas do windons: Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

-> pip install beautifulsoup4
